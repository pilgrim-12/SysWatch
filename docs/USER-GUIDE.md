# Руководство пользователя

SysWatch работает в двух частях. **Агент** — служба Windows, которая с момента включения компьютера записывает, что происходит. **Окно** открывается кликом по иконке в трее и показывает записанное. Закрыть окно можно в любой момент: агент продолжит работу.

Слева — разделы, сверху — живые графики, внизу левой панели — язык, версия и состояние агента («Агент пишет данные» — всё в порядке).

---

## Верхняя полоса

Последние 2 минуты, обновление раз в секунду:

- **Процессор** — загрузка всех ядер, число процессов.
- **Память** — занято из всего.
- **Диск** — чтение + запись в секунду, пик за 2 минуты.
- **Сеть** — входящий ↓ и исходящий ↑ трафик.
- **Видеокарта / Видеокарты** — загрузка как в Диспетчере задач. Если карт несколько, у каждой своя линия, внизу — «RTX 4060 33% · Intel UHD 13%». Клик открывает раздел «Видеокарта». Нет плитки — Windows не отдаёт счётчики (например, в виртуальной машине).

## Обзор

Оценка 0–100 и список проблем по важности: мало места, ошибки диска, сбои, перегрев, изношенная батарея, аномалии, программы без подписи в автозагрузке, устаревшие SDK. У каждой проблемы — кнопка в нужный раздел.

## Сейчас

Живой список программ (несколько процессов одной программы сложены), топ за последний час и блок «Сколько стоит мониторинг» — процессор и память самого агента. Клик по программе открывает её карточку: графики, подпись, куда подключалась; там же — завершить, сменить приоритет, показать файл.

## Соединения

Все текущие соединения: программа, адрес, домен, страна, состояние. Переключатель **Таблица / Карта**: на карте исходящие — голубые, входящие — жёлтые. Локальные адреса (`127.0.0.1`, домашняя сеть) по умолчанию скрыты. Пустая карта входящих — нормально: обычно входящих соединений из интернета нет.

## Таймлайн

- **Вся система** — процессор, память и видеокарты по минутам за час, 6 часов, сутки, неделю или месяц. Над графиком — легенда.
- **Программы по минутам** — тепловая карта: чем ярче клетка, тем больше программа нагружала в эту минуту. Переключатель: процессор, память, сеть.
- **Снимок момента** — клик по минуте на графике или карте показывает, кто что делал в эту минуту.

График начинается с первой записанной минуты: раньше агент не работал.

## Сеть

Куда программы отправляют данные.

- **Карта** — страны с трафиком, дуги от вашей страны. Колесо — масштаб, перетаскивание — сдвиг. Клик по стране — какие программы и адреса туда ходили.
- **Страны** — список с объёмами.
- **Программы** — точная связка «программа → адрес → страна → отправлено/получено».

Страна определяется по офлайн-базе: один раз нажмите «Скачать базу стран». После этого адреса никуда не отправляются. Ваша страна берётся из часового пояса Windows.

## Аномалии

Правила, которые срабатывают сами, с уведомлением в трее:

| Правило | Когда |
|---|---|
| Неподписанная программа в сети | программа без цифровой подписи соединяется с интернетом |
| Запуск из временной папки | exe запущен из `Temp` или `Downloads` |
| Новая программа | программа запущена впервые |
| Новый домен | программа обратилась к домену впервые |
| Автозагрузка | появилась новая запись в автозагрузке |
| Открытый порт | программа принимает соединения из сети |
| Процессор / память | программа долго держит высокую нагрузку |

Правило можно отключить для конкретной программы, если срабатывание ожидаемое. Собственный установщик SysWatch и подписанные приложения Microsoft Store в аномалии не попадают.

## Диск

Раз в сутки, когда компьютер не занят, SysWatch делает снимок диска (папки и файлы от 100 МБ). Кнопка «Сканировать C:» делает снимок сразу.

**Поиск файлов** (вверху раздела):

| Ввести | Найдёт |
|---|---|
| `отчёт` | имя содержит «отчёт» |
| `*.pdf` или `.pdf` | все PDF |
| `*.mp4 *.mkv` | MP4 и MKV |
| `IMG_*.jpg` | по маске, как в проводнике |
| `договор .docx` | Word-файлы со словом «договор» |

Дополнительно: тип (видео, документы, архивы…), размер, дата изменения, диск, «и папки». Результаты сортируются по размеру, дате, имени. «На карте» открывает папку на карте и подсвечивает место голубым маяком; «В проводнике» — открывает проводник с выделенным файлом. Не больше 1000 результатов; индекса нет, каждый поиск — свежий обход.

**Что занимает место** — три вида:
- **Карта** — прямоугольники, площадь = размер. Внутри видно подпапки. Клик — зайти.
- **Список** — с понятными подписями: «Обновление Microsoft Edge», «Кэш npm», «Временные файлы».
- **3D** — город: папки — прямоугольные здания, файлы — шестигранные кристаллы, цвет по типу (легенда в углу). Мелкие файлы открытой папки — отдельный квартал. Мышь — вращать, колесо — приблизить, правая кнопка — сдвинуть, клик по папке — зайти, по файлу — показать в проводнике.

**Файлы в папке** — под картой: все файлы открытой папки сейчас, с фильтром и скрытыми файлами. Мелкие подпапки открываются прямо в списке.

**Что выросло** — папки, выросшие больше чем на 300 МБ со вчерашнего или прошлонедельного снимка.

**Корзина** — объём, что внутри (откуда удалено и когда), «Восстановить», «Удалить навсегда», «Очистить Корзину». Необратимые действия спрашивают подтверждение.

**Можно очистить** (только системный диск) — временные файлы, кэши, старые обновления, кэши разработки. Отмечено заранее только безопасное; «Проверить вручную» — решать вам. Удалённое «навсегда» вернуть нельзя, «в Корзину» — можно.

OneDrive считается как обычная папка; файлы «только в облаке» места на диске не занимают и в размер не входят.

## Программы

Установленные программы с размером, датой установки и **последним запуском** — видно, чем давно не пользуетесь. Удаление — штатным деинсталлятором. Обновления — через winget: видно, что можно обновить, обновление по одной программе или всех сразу.

## Система

- **О компьютере** — модель, Windows, учётная запись, защита (BitLocker, Secure Boot, TPM), процессор, память, видеокарты, экраны (модель, разрешение, частота, подключение), диски, сеть, порты, звук. Точки восстановления: список и «Создать точку».
- **Автозагрузка** — включить/выключить, подпись издателя.
- **Диски** — здоровье (SMART), износ SSD, ошибки.
- **Батарея** — износ, циклы, время работы.
- **Пробуждения** — что будило компьютер.
- **Сбои** — синие экраны, внезапные выключения, падения программ с понятным объяснением кода ошибки.

## Видеокарта

Загрузка по движкам (3D, видео, вычисления), видеопамять, температура, мощность, вентилятор, программы на видеокарте. Несколько записей одной карты объединяются, виртуальные адаптеры скрыты.

## Разработка

SDK и среды (.NET, Node.js, Python, Java…) с версиями, датами окончания поддержки и размером; Docker (образы, контейнеры, очистка); старые `node_modules`; службы разработки (SQL Server, Redis…).

## История

Поиск и посещения из Chrome, Edge, Firefox текущего пользователя: поиск по тексту, фильтры, топ сайтов. Выборочное удаление: если браузер открыт, удаление выполнится после его закрытия.

## Отчёты

«Здоровье ПК», «Неделя», «Безопасность», «Сеть», «Разработка» — открыть в окне, сохранить в PDF или HTML, получать по расписанию в `Документы\SysWatch\Reports`. «Почему тормозило?» разбирает каждую перегрузку: кто виноват.

## Настройки

- **Хранение истории** — 30, 90, 180 или 365 дней; сколько дней хранить сетевые подробности. Видно, сколько места занимает история.
- **Оповещения** — процессор или память выше порога N минут подряд, мало места на диске, горячая видеокарта. Не чаще раза в час на каждый тип.

## Частые вопросы

**Собирает ли SysWatch данные, когда окно закрыто?** Да, это делает агент. Окно только показывает.

**Сколько он потребляет?** Раздел «Сейчас» → «Сколько стоит мониторинг». Обычно меньше 0,5% процессора и 50 МБ памяти.

**Почему SmartScreen предупреждает?** Установщик не подписан платным сертификатом. Проверка подлинности — в [README](../README.md#установка).

**Куда отправляются мои данные?** Никуда. Подробно — [PRIVACY.md](PRIVACY.md).
