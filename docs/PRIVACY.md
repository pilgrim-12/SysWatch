# Конфиденциальность

Коротко: **SysWatch ничего не отправляет в интернет.** Всё, что он собирает, лежит на вашем компьютере в `C:\ProgramData\SysWatch` и удаляется вместе с программой, если выбрать «удалить данные».

## Что собирается

| Что | Откуда | Где хранится | Сколько |
|---|---|---|---|
| Процессы: имя, путь, командная строка, родитель, время запуска и выхода | ETW ядра Windows | `hot\YYYY-MM-DD.db`, таблица `process` | срок хранения (90 дней); командные строки — 30 дней |
| Нагрузка по минутам: процессор, память, диск, сеть по программам | Win32 API, раз в 5 с | `proc_1m`, `system_1m` | срок хранения |
| Соединения: программа → IP:порт, домен, байты | ETW ядра + ETW DNS | `conn_1m`, `dns` | 30 дней |
| Видеокарта: загрузка, память, температура, программы | счётчики Windows, D3DKMT, `nvidia-smi` | `gpu_1m`, `gpu_proc_1m` | срок хранения; по программам — 30 дней |
| Снимки диска: папки и файлы от 100 МБ | обход диска раз в сутки | `disk.db` | последние снимки |
| Найденные аномалии | правила в окне | `anomalies.db` | пока не удалите |
| Результат проверки безопасности | раздел «Безопасность» | `security.json` | только последний |
| Настройки | окно | `settings.json` | — |

**Не собирается:** содержимое файлов, содержимое трафика (HTTPS не расшифровывается), нажатия клавиш, снимки экрана, пароли.

**Командные строки** иногда содержат секреты (токены в параметрах). Хранение отключается параметром `StoreCommandLines: false` в `appsettings.json` агента.

## Что читается, но не хранится

- **История браузеров** (раздел «История»): читается копия базы Chrome, Edge, Firefox **только текущего пользователя Windows**, в момент открытия раздела. В базы SysWatch не попадает.
- **Поиск файлов и «Файлы в папке»**: обход диска по запросу, результаты живут, пока открыто окно. Индекса нет.
- **Корзина**: список читается из `$Recycle.Bin` текущего пользователя при открытии раздела.
- **Сведения о компьютере**: WMI и реестр, по запросу.

## Когда SysWatch выходит в сеть

Только по вашему действию:

| Действие | Куда |
|---|---|
| «Скачать базу стран» в разделе «Сеть» | `download.db-ip.com` — бесплатная офлайн-база «IP → страна»; сохраняется в `C:\ProgramData\SysWatch\geo` |
| «Проверить обновления» / «Обновить» в «Программах» | `winget` — менеджер пакетов Windows, обращается к своим источникам |

Определение страны по IP после скачивания базы идёт **офлайн**: адреса никуда не отправляются. Страна этого компьютера определяется по часовому поясу Windows.

## Удаление данных

- Удалить программу с данными: «Приложения» Windows → SysWatch → удалить → «Да» на вопрос об истории; либо `.\scripts\uninstall.ps1 -RemoveData`.
- Вручную: удалить папку `C:\ProgramData\SysWatch`.
- Отчёты лежат отдельно: `Документы\SysWatch\Reports`.
