# SysWatch

Личный монитор Windows: кто грузит процессор, память, диск, сеть и видеокарту, куда программы отправляют данные, что занимает место на диске и что с компьютером не так. Работает фоном, почти ничего не потребляет и **ничего никуда не отправляет**.

**Версия 1.2.0** · Windows 10 1809+ / Windows 11 x64 · интерфейс на русском, английском, испанском и французском

## Что умеет

| Раздел | Коротко |
|---|---|
| Обзор | оценка здоровья 0–100 и список «что стоит сделать» со ссылками |
| Верхняя полоса | живые графики за 2 минуты: процессор, память, диск, сеть, видеокарты (каждая своей линией) |
| Сейчас | живой список программ, топ за час, сколько стоит сам мониторинг |
| Соединения | живые соединения: таблица или карта мира (исходящие и входящие) |
| Таймлайн | загрузка по минутам (процессор, память, видеокарты), тепловая карта программ, снимок любой минуты |
| Сеть | «программа → адрес → страна», карта мира с масштабом, страны, новые адреса за сегодня |
| Аномалии | неподписанные программы в сети, запуск из Temp, новые программы и автозагрузка, открытые порты |
| Диск | карта, список и 3D-город папок; файлы в папке; поиск файлов с отметками на карте; Корзина; очистка; что выросло |
| Программы | установленные программы, последний запуск, обновления через winget, удаление |
| Система | «О компьютере» (учётная запись, компоненты, экраны, порты, точки восстановления), автозагрузка, диски, батарея, сбои |
| Видеокарта | загрузка по движкам, видеопамять, температура, программы на видеокарте |
| Разработка | SDK и среды с датами поддержки, Docker, старые `node_modules`, службы |
| История | поиск и посещения из Chrome, Edge, Firefox; выборочное удаление |
| Отчёты | «Здоровье ПК», «Неделя», «Безопасность», «Сеть», «Разработка»; PDF/HTML, по расписанию |
| Настройки | срок хранения истории, пороги оповещений |

## Установка

Скачать `SysWatch-Setup-1.2.0.exe` из [Releases](https://github.com/pilgrim-12/SysWatch/releases) и запустить. .NET ставить не нужно — он внутри установщика.

Проверить, что файл не подменён:

```powershell
Get-FileHash .\SysWatch-Setup-1.2.0.exe -Algorithm SHA256   # сравнить с SysWatch-Setup-1.2.0.exe.sha256 из релиза
gh attestation verify .\SysWatch-Setup-1.2.0.exe --repo pilgrim-12/SysWatch   # собран GitHub из этого репозитория
```

Установщик не подписан цифровой подписью, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

После установки:
- служба `SysWatchAgent` собирает данные с запуска Windows;
- SysWatch стартует в трей при входе; клик по иконке открывает окно;
- закрытое окно выгружается из памяти, агент продолжает работать.

## Сборка из исходников

Нужно: .NET 10 SDK (`winget install Microsoft.DotNet.SDK.10`), Node.js 22 — только если меняете интерфейс.

```powershell
cd C:\GIT\SysWatch
.\scripts\build-installer.ps1                       # → installer\Output\SysWatch-Setup-<версия>.exe
.\installer\Output\SysWatch-Setup-1.2.0.exe         # установить
```

Интерфейс уже собран в `src/SysWatch.App/wwwroot`. После правок в `src/ui`:

```powershell
cd src\ui
npm install
npm test           # проверки: переводы, форматы, подписи путей
npm run build      # сборка в src/SysWatch.App/wwwroot
npm run dev        # разработка в браузере на тестовых данных, без Windows
```

Для разработки без установщика: `.\scripts\install.ps1` (от администратора) ставит службу и автозапуск из исходников, `.\scripts\uninstall.ps1 [-RemoveData]` удаляет.

## Новая версия

1. Поменять `<Version>` в `Directory.Build.props` — версия одна на агент, окно и установщик.
2. Дописать [CHANGELOG.md](CHANGELOG.md).
3. `git commit`, затем `git tag v1.2.0; git push; git push --tags`.

GitHub Actions соберёт установщик, посчитает SHA-256, добавит аттестацию и опубликует релиз.

## Данные

`C:\ProgramData\SysWatch\hot\YYYY-MM-DD.db` — один SQLite-файл на день. По умолчанию 90 дней (30–365 в «Настройках»). Через 30 дней из файла удаляются сетевые подробности и командные строки, поминутная нагрузка остаётся. Подробно — в [ARCHITECTURE.md](docs/ARCHITECTURE.md#данные).

## Ограничения

- Содержимое HTTPS не видно: видно процесс, IP, порт, домен (через DNS) и объём.
- Программы со своим DNS (DNS-over-HTTPS в браузере) могут оставаться без домена.
- Процессы короче 5 секунд видны, но их процессор может не попасть в замер.
- Температура видеокарты — только если драйвер её отдаёт (для NVIDIA есть запасной путь через `nvidia-smi`).
